# bingbing

MIDI-controllable softsynth for the HAIKU OS with configurable voices. Idea is to have basic operators which can be interconnected and parameterized to define a voice. 
Parameters can be tagged for inclusion in a dynamically created control UI where they are displayed as sliders, knobs or switches. The user can layout the position of the control widgets into a functionally structured panel and also select the widget to be used per parameter.
